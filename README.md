# 🎓 SchoolLoop — The Super App for South African Schools

## Project Overview

SchoolLoop is a web-based platform designed to modernise and digitise school management in South Africa.

It addresses major challenges in public schools such as manual administration, poor parent communication, lack of real-time performance tracking, and high learner dropout rates.

The system provides a centralised platform for teachers, parents, and school principals to manage, monitor, and improve the educational experience.



## Problem Statement

Many South African schools still rely on outdated manual systems:

* Paper-based attendance registers and mark sheets
* Delayed or missing communication with parents
* No real-time visibility into learner performance
* Lack of early detection for at-risk students

These challenges contribute to inefficiency and increased dropout rates.



## Solution

SchoolLoop introduces a digital ecosystem that:

* Automates attendance and mark capturing
* Provides real-time communication between teachers and parents
* Enables performance tracking and analytics
* Identifies at-risk learners early using data insights



## System Portals

### Teacher Portal

* Record attendance
* Capture learner marks
* Send notifications to parents
* Track learner performance

### Parent Portal

* Receive real-time notifications
* View learner performance
* Access school announcements
* Communicate with teachers

### Principal Portal

* Monitor attendance in real-time
* View performance trends
* Manage timetables
* Access school-wide analytics



## Key Features

* Real-time attendance tracking
* Automated performance calculations
* Parent notification system
* AI-powered language translation
* Resource sharing marketplace
* Offline-tolerant functionality



## Technologies Used

* Frontend: Next.js, React, Tailwind CSS
* Backend: Node.js, NestJS
* Database: PostgreSQL, Redis
* AI Integration: Claude API
* Cloud & Deployment: AWS, Docker
* Version Control: GitHub
